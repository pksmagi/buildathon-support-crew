WHAT THIS PROJECT DOES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

You enter a question:
   "How do I reset my password?"
           |
           v
Three AI agents run sequentially:
   
   AGENT 1: Knowledge Assistant
   Answers from training knowledge
   Provides baseline response
      
   AGENT 2: Web Search Assistant
   Searches the web for current information
   Finds 2-3 authoritative sources
   Provides current 2024 practices
   References and compares with Agent 1
      
   AGENT 3: Documentation Agent
   Synthesizes both perspectives
   Writes to answers.txt file
   Returns both answers to you

You see:
   Agent 1's answer (Knowledge-based)
   Agent 2's answer (Web-sourced)
   File saved confirmation
   Both answers to download


THREE PROFESSIONAL AGENTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

AGENT 1 - Knowledge Assistant
  Role: Expert Support Specialist (15+ years)
  Tools: None (knowledge only)
  Input: Your query
  Output: Knowledge-based answer
  Quality: 7-part structured response

AGENT 2 - Web Search Assistant
  Role: Technology Specialist (15+ years research)
  Tools: Web search (Serper API)
  Input: Your query + Agent 1's answer
  Comparative Analysis: How does web info differ from knowledge?
  Output: Current web-sourced answer
  Quality: 2-3 sources minimum, 7-part response

AGENT 3 - Documentation Agent
  Role: Documentation Expert (15+ years)
  Tools: File save
  Input: Query + Agent 1 + Agent 2 answers
  Synthesis: Combine both perspectives
  Output: Professional .txt file + confirmation
  Quality: Comprehensive, well-formatted documentation
